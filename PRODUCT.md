# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Open decision: no single primary audience confirmed yet. Visitors are prospective clients evaluating whether to hire the agency for one or more services.

## Product Purpose
Marketing site for a multi-service creative and digital agency. It presents what the agency does (Our Services, at `/`) and the work it has done (Portfolio, at `/portfolio`) so a prospect can judge fit and start a project.

## Capabilities and Constraints
- Services offered: Web Development, Brand Design, Digital Marketing, SEO Optimization, Graphic Design, Video Editing, Motion Graphics, AI Automation (`src/components/services/data.ts`).
- Built with Next.js 16 (App Router), React 19, Tailwind CSS 4, framer-motion, lucide-react.
- The agency is unnamed in copy; neutral "studio" wording is used (e.g. `studio://services`).

## Evidence on Hand
No real case studies, client names, metrics, testimonials or project imagery exist yet. Portfolio content is explicitly dummy placeholder data and must be swapped for real work before launch; do not present it as genuine.

## Product Principles
- Show the work running, not described: each service and project is demonstrated live on screen.
- Every service should be traceable to work that proves it.
- The prospect should always have a clear next step to start a project.
